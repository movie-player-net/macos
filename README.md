# Movie Player for macOS: LGPL Relink Kits

Movie Player for macOS uses [VLCKit](https://code.videolan.org/videolan/VLCKit) (libVLC), which is licensed under the GNU Lesser General Public License 2.1.

Each [release](https://github.com/movie-player-net/macos/releases) contains a relink kit for the matching Movie Player version. A kit holds the app's compiled object code, its prebuilt frameworks and resources, and an Xcode project for relinking the app against a modified VLCKit. See the README inside each kit for instructions.
